LYRA GALLERY — ADD YOUR REAL BIKE PHOTOS
============================================

1. Drop photos here, e.g.:
     lyra-1.jpg … lyra-6.jpg  (jpg/webp, ~1600px wide, <500 KB each)

2. Open lib/data.ts → GALLERY array and set each `src`:
     { src: "/gallery/lyra-1.jpg", title: "Night Stare", tag: "FRONT" }

Empty `src` ("") renders the styled placeholder slot you see now,
so nothing ever looks broken before your photos are added.
